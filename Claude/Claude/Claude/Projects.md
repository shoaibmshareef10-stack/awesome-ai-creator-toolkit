# Claude Projects

## What are Claude Projects?

Claude Projects help you organise conversations, files, and instructions in one dedicated workspace. They are useful for long-term work where you want Claude to remember the context within that project.

---

## Key Features

- Dedicated workspace
- Upload reference documents
- Reusable project instructions
- Better context management
- Organised chats

---

## When to Use Projects

- Building software
- Writing books or articles
- Research projects
- Business planning
- Learning new skills
- Team documentation

---

## How to Create a Project

1. Open Claude.
2. Click **Projects**.
3. Select **New Project**.
4. Give your project a name.
5. Add project instructions.
6. Upload supporting files if needed.
7. Start chatting with Claude.

---

## Best Practices

- Use clear project names.
- Keep project instructions updated.
- Upload only relevant files.
- Create separate projects for different topics.
- Review and refine instructions regularly.

---

## Example

Project Name:
AI Creator Toolkit

Project Instruction:
"You are an AI documentation expert. Help create beginner-friendly guides with practical examples and Markdown formatting."
